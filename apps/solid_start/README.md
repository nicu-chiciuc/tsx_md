# solid_start

Minimal SolidJS + TanStack Start app with file-based routing.

- `/` is prerendered at build time.
- `/about` is handled through the SPA shell so it works on Cloudflare Pages.
- Tailwind is used for layout and link styling.
- A small shadcn-style button primitive lives in `src/components/ui/button.tsx`.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
```
